# Grey's Anatomy Hospital

App de prontuário **de enfermagem** feito com alunos de Enfermagem, para o Trabalho Prático de
Experiência do Usuário (profª Francielle Barros). A equipe registra passagem de plantão e evolução,
sinais vitais, medicações, exames e observações, e acompanha tudo no histórico do paciente.
Tem também uma página do Setembro Amarelo.

**Acesse:** https://____.netlify.app

Feito com HTML, CSS e JavaScript puro, banco de dados Supabase e hospedagem no Netlify.
Funciona no navegador e pode ser instalado no celular como app.

> **Todos os dados são fictícios.** O site é público: nunca cadastre pacientes reais.
